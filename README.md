# Inkstead

Inkstead is an opinionated publishing engine for personal indie websites. Write in Markdown, build a static site, deploy anywhere, and optionally syndicate posts to social media.

## Get Started

The full documentation is available at [inkstead.dev](https://inkstead.dev/).

Create a new site:

```bash
npx inkstead init my-site
cd my-site
npm install
npm run doctor
npm run dev
```

`init` asks which deployment, CI, and syndication adapters to configure.
